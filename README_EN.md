## Introduction
**P5XTES Patcher** is a fan-made project designed as an all-in-one ecosystem for *Persona 5: The Phantom X* (P5X). Originally focused on Spanish translation, it has evolved into a comprehensive management tool that allows you to install visual mods, customize the protagonist's name, hide interface elements (UI/ID), and easily manage technical game configurations using plugins like **BepInEx** and **XUnity.AutoTranslator**.

## Why this project?
The global version of *Persona 5: The Phantom X* was released exclusively in English, which makes it difficult for Spanish-speaking players to fully enjoy the narrative. This project aims to bridge that gap, allowing everyone to immerse themselves in the full game experience without language barriers. Furthermore, we understand that technical setup can be complex; therefore, P5XTES Patcher centralizes all the necessary tools to personalize your experience and improve your quality of life within the game in an accessible and secure way.

## What is P5XTES Patcher?
**P5XTES Patcher** is the all-in-one management tool designed to enhance and customize your *Persona 5: The Phantom X* experience. More than just an installer, it acts as a centralized ecosystem that allows users to intuitively manage translations, mods, and game settings.

## Main Features
The Patcher has been developed to simplify complex technical processes into a user-friendly interface:

*   **Comprehensive Translation Management**: Implement Spanish translations (Global/SEA version) or English translations (KR, TW, CN servers), with the ability to toggle the auto-translator on or off as needed.
*   **Integrated Mod Manager**: An advanced manager that allows you to install, update, and manage additional mods (such as UI improvements or visual adjustments) without complications. It supports batch installation and version control.
*   **Protagonist Customization**: A dedicated tool to configure and personalize the protagonist's name directly from the Patcher.
*   **Privacy and Streaming**: Includes a one-click "Hide ID" feature, ideal for content creators who wish to protect their player ID during streams or captures.
*   **Multi-Server Compatibility**: Automatically detects the game path and adapts the necessary components depending on the server you are playing on.
*   **Multi-Platform Support**: Optimized for Windows and Linux (Steam Deck), eliminating the need for complex manual configurations.
*   **Automatic Updates**: Checks for new versions of the *Core*, text files, and textures, keeping your game up to date.

## 🛠️ Why use P5XTES Patcher?
We know the global version of the game presents language and technical hurdles. This program was created to centralize all necessary solutions in one place:

1.  **Centralization**: No need to search for scattered files online; the Patcher downloads and installs the *Core* needed to get everything running.
2.  **Security**: Ensures you use the correct components (such as the specific version of BepInEx) that guarantee the game remains stable and compatible.
3.  **Ease of Use**: Change the interface language (Spanish/English), manage your servers, and control your mods from a unified control panel.
